- Fazer um algoritmo para ler os números de -10 até 10 e dizer quantos são positivos/negativos, pares/impares.
1. Desenvolver a estrutura básica (Public class e main)
2. Define as variáveis e valores (inicio, fim, positivos, negativos, pares, ímpares)
3. inicia o laço de repetição (Neste caso é recomendado o for, pois o range está delimitado)
4. Verificar se é positivo/negativo e par/ímpar (Usar estrutura if/else)
5. Dentro do if/else, inserimos/adicionamos +1 no valor dentro das variáveis para cada condição.
6. Sai do if, sai do for e imprime o valor de cada variável
