# Programação do Curso Java

Programação de um curso de Java baseada na grade do curso **Java COMPLETO Programação Orientada a Objetos + Projetos**, do professor Nélio Alves, na Udemy.

O curso começa diretamente pelo conteúdo. As cinco aulas iniciais de apresentação da grade de referência não fazem parte desta programação. Por isso, a **aula 6 da referência corresponde à aula 1 deste curso**.

Este README cobre, por enquanto, as aulas 6 a 88 da referência, que correspondem às **aulas 1 a 83 do curso**.

## Referências
- OCPJ21 Study Guide [ https://github.com/eh3rrera/ocpj21-book ]
- Certificação Oracle Certified Professional, Java SE 25 Developer - exame 1Z0-831 [ https://education.oracle.com/java-se-25-developer-professional/pexam_1Z0-831 ]

> Não existe um repositório `ocpj25-book`. O autor do `ocpj21-book`, Esteban Herrera, mantém `ocpj8-book`, `ocpj8-notes`, `ocpj17-book` e `ocpj21-book`, mas nenhum voltado ao Java 25 até agosto de 2026. O `ocpj21-book` segue como base, complementado pelos materiais das seções.
