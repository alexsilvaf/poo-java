# Seção 17 — Streams, Collectors e Gatherers

<sub>📚 [Documentação](../README.md) › Seção 17</sub>

## 🎯 Objetivos

- montar pipelines lazy de streams de objetos e primitivos;
- filtrar, transformar, decompor, ordenar, limitar e concatenar;
- reduzir e coletar resultados;
- agrupar, particionar e criar mapas;
- usar streams paralelas com segurança;
- aplicar Gatherers, finalizados antes da OCPJ25.
