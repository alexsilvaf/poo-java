# Seção 18 — I/O, NIO.2 e serialização

- distinguir byte streams e character streams;
- compor streams com buffering;
- construir e normalizar `Path`;
- ler, gravar, copiar, mover, excluir e percorrer com `Files`;
- consultar atributos;
- serializar objetos e analisar `transient`, `static` e `serialVersionUID`.
