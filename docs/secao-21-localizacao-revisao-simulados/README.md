# Seção 21 — Localização, revisão integrada e simulados OCPJ25

## 🎯 Objetivos

- selecionar e construir `Locale`;
- formatar e interpretar números, moedas, porcentagens e datas;
- usar resource bundles e compreender fallback;
- formatar mensagens;
- revisar todos os domínios em questões integradas;
- aplicar uma estratégia consistente de leitura para a OCPJ25.
