# O que precisaremos?

- Linguagem de programação
- Editor de código ou IDE
- Compilador ou interpretador
- Ambiente de execução, quando exigido pela linguagem

## O que é uma linguagem de programação?

Uma linguagem de programação define regras **léxicas**, **sintáticas** e **semânticas** para escrever programas que possam ser traduzidos e executados por um computador.

## O que é uma IDE?

É um software que reúne ferramentas para editar, traduzir, executar e depurar programas. Uma IDE facilita o desenvolvimento, mas não é obrigatória para criar um programa.

## O que é um compilador?

É um software que traduz o código-fonte antes da execução. Dependendo da linguagem e da plataforma, o resultado pode ser código objeto, código intermediário ou um executável nativo.

O código objeto nem sempre pode ser executado diretamente: ele pode precisar ser combinado com outros arquivos por um ligador (*linker*) ou executado por um ambiente específico.

## O que é um interpretador?

É um software que analisa e executa o programa de forma progressiva. Uma implementação pode criar representações intermediárias internamente, mesmo quando a linguagem é classificada como interpretada.

## O que é uma máquina virtual?

É um ambiente de execução que funciona como uma máquina abstrata. Ela carrega e executa código intermediário e pode interpretá-lo ou compilá-lo para código nativo durante a execução.
