# O que precisaremos?
- Linguagem de programação
- IDE
- Compilador
- Máquina Virtual

# O que é uma linguagem de programação?
Linguagem de programação é um conjunto de regras **léxicas** e **sintáticas** para se escrever o programa

# O que é uma IDE?
É um software utilizado para editar e testar o seu programa. Basicamente, é um editor de texto com ferramentas adicionais para desenvolvedores.

# O que é um compilador?
É um software com papel de transformar o código fonte, que é o código diretamente escrito pelo programador, em código objeto, que é um codigo que pode ser executado pela máquina.

# O que é um gerador de código ou máquina virtual?
Um gerador de código ou máquina virtual é um software que permite que o programa seja executado
