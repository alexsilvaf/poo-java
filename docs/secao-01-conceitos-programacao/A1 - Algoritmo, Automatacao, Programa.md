# Algoritmo, Automação, Programa de Computador

## O que é um algoritmo?

Um algoritmo é uma sequência finita e ordenada de instruções para realizar uma tarefa ou resolver um problema.

### Exemplo

Como lavamos uma roupa suja?

1. Colocamos a roupa em um recipiente
2. Colocamos um pouco de sabão e amaciante
3. Enchemos o recipiente com água
4. Mexemos até dissolver o sabão
5. Deixamos de molho por vinte minutos
6. Esfregamos a roupa
7. Enxaguamos
8. Torcemos

## O que é automação?

Automação é o uso de uma máquina ou sistema para executar um procedimento de forma automática ou semiautomática.

## O que é um programa de computador?

Um programa de computador é um conjunto de instruções escrito em uma linguagem de programação. Essas instruções representam algoritmos que o computador consegue executar para automatizar tarefas.

Nem todo algoritmo descreve uma tarefa computacional. Um computador não lava uma roupa, por exemplo, mas pode controlar uma máquina de lavar. Entre as tarefas computacionais estão:

- receber e apresentar dados;
- processar dados;
- realizar cálculos;
- tomar decisões com base em condições;
- repetir operações.
