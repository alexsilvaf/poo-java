# Algoritmo, Automação, Programa de Computador
## O que é um algoritmo?
Um algoritmo é um conjunto de instruções para se executar determinada tarefa.

### Exemplo:
Como lavamos uma roupa suja?
 1. Colocamos roupa em um recipiente
 2. Colocamos um pouco de sabão e amaciante
 3. Enchemos de água
 4. Mexemos tudo até dissolver todo o sabão
 5. Deixamos de molho por vinte minutos
 6. Esfregamos a rouba
 7. Enxaguamos
 8. Torcemos

## O que é automação?
Consiste em utilizar uma máquina para executar um procedimento de forma automática ou semi automática.

## O que é um programa de computador?
Programas são algoritmos executados por um computador. Portanto, o computador é uma máquina que executa uma sequencia de instruções, chamada algoritmo, automatizando uma tarefa.
Vale lembrar que nao é qualquer algoritmo, pois algoritmos são uma sequencia de instruções. Computador nao lava roupa suja, por exemplo. Ele executa apenas algoritmos computacionais, tais como:
- Processamento de dados
- Cálculos
