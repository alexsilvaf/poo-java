# Seção 15 — Collections, ordenação e generics

<sub>📚 [Documentação](../README.md) › Seção 15</sub>

## 🎯 Objetivos

- escolher entre `List`, `Set`, `Map`, `Deque` e interfaces sequenciadas;
- adicionar, remover, atualizar, recuperar e ordenar elementos;
- aplicar `equals`/`hashCode`, `Comparable` e `Comparator`;
- criar tipos e métodos genéricos;
- usar wildcards com limites superiores e inferiores;
- explicar invariância, erasure e restrições de generics.
