# Seção 20 — Concorrência, virtual threads e scoped values

<sub>📚 [Documentação](../README.md) › Seção 20</sub>

## 🎯 Objetivos

- criar tarefas com `Runnable` e `Callable`;
- distinguir threads de plataforma e virtuais;
- usar executores, `Future` e coleções concorrentes;
- reconhecer race condition, deadlock, starvation e livelock;
- proteger estado com `synchronized`, locks e tipos atômicos;
- usar scoped values finalizados no Java 25;
- raciocinar sobre streams paralelas.
