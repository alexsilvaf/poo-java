# Seção 19 — JPMS, JARs, ferramentas e execução

<sub>📚 [Documentação](../README.md) › Seção 19</sub>

## 🎯 Objetivos

- compilar e executar no classpath e module path;
- criar JARs modulares e não modulares;
- declarar `requires`, `exports`, `opens`, `uses` e `provides`;
- distinguir módulos nomeados, automáticos e sem nome;
- analisar dependências com `jdeps` e criar imagens com `jlink`;
- usar `import module`, compact source files, instance `main` e programas multifonte.
