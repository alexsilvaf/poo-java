# O que é Java?
- Linguagem de programação (Regras lexicas, sintáticas e semânticas)
- Plataforma de desenvolvimento e execução
    - Bibliotecas (API)
    - Ambiente de execução

## Historico
- Problemas resolvidos e motivo de seu sucesso:
    - **Ponteiros / gerenciamento de memória:**
        No final da década de 80, os desenvolvedores tinham muitos problemas relacionados a ponteiros, gerenciamento de memória, muitas linguagens amplamente utilizadas, como C, necessitavam de definir explicitamente quais variáveis eram ponteiros e quais eram valor através de controle manual. Isso fazia com que essas fossem linguagens chamadas de Baixo Nível e os softwares eram mais sucetíveis a erros/bugs. Java veio para eliminar esta dificuldade
    - **Portabilidade falha: reescrever parte do código ao mudar de SO:**
        Embora uma linguagem como C tivesse um padrão e possuísse compiladores para várias plataformas, quando o programador compilava este código para plataformas diferentes, eventualmente ele precisava reescrever parte do código e alterar algumas coisas para adaptar aquele programa para o Sistema Operacional. Isso sempre foi uma dificuldade de linguagens compiladas.
    - **Utilização em dispositivos diversos:**
    - **Custo:**
        Muitas vezes era desejado rodar o mesmo programa em vários dispositivos, e as linguagens de programação da época possuiam dificuldade de portabilidade, que causava aumento de custos e dificuldade de execução.

- Criada pela Sun Microsystems no meio da década de 1990
- Adquirida pela Oracle Corporation em 2010

## Aspectos notáveis
- Código compilado para bytecode e executado em uma máquina virtual (JVM)
- Portável, segura e robusta
- Roda em vários tipos de dispositivos
- Domina o mercado corporativo desde o fim do século 20
- Padrão Android por muitos anos

## Edições:
- Java ME - Java Micro Edition - dispositivos embarcados e móveis - IoT
- Java SE - Java Standart Edition - core - desktop e servidores
- Java EE - Java Enterprise Edition - aplicações corporativas
