BLOCO 1 DE 6

Contextualização e edições do Java

O que é Java?

Duas coisas ao mesmo tempo

  • Linguagem de programação — com suas próprias regras léxicas, sintáticas e semânticas.
  • Plataforma de desenvolvimento e execução — bibliotecas (API) mais um ambiente de execução (a JVM).
Criada pela Sun Microsystems em meados dos anos 1990; adquirida pela Oracle em 2010.
Por que o Java fez sucesso

Três problemas que ele veio resolver

  • Ponteiros e gerenciamento de memória — em C, o programador controlava ponteiros manualmente; Java automatiza isso.
  • Portabilidade falha — um programa compilado em C muitas vezes precisava de ajustes ao mudar de sistema operacional.
  • Custo e diversidade de dispositivos — rodar o mesmo programa em várias máquinas era caro e trabalhoso.
Linguagem compilada — C / C++

Um executável por sistema operacional

O mesmo código-fonte passa por um compilador diferente para cada SO — e às vezes precisa de ajustes.
Linguagem interpretada — PHP, Python, JavaScript

Sem executável: sempre um interpretador

Portátil por natureza, mas depende de um interpretador instalado — e tende a ser mais lento.
Linguagem híbrida — a resposta do Java

Compila uma vez, roda em qualquer JVM

"Write once, run anywhere" — o bytecode é o mesmo em qualquer sistema; quem se adapta é a JVM.

Portável, segura e robusta, domina o mercado corporativo desde o fim dos anos 90 — e foi o padrão do Android por muitos anos.

Plataforma Java SE

Três siglas, uma contenção

JDK ⊃ JRE ⊃ JVM

SiglaNomeO que é
JVMJava Virtual MachineCarrega, verifica e executa o bytecode
JREJava Runtime EnvironmentJVM + bibliotecas padrão — mínimo para executar

Do código-fonte ao processador

Modelo de execução do Java

Componentes internos

O que existe dentro da JVM

  • Class Loader — localiza e carrega os .class sob demanda.
  • Verificador de bytecode — valida o código antes de executar.
  • Áreas de memória — heap (objetos), stack (chamadas e variáveis locais), metaspace (metadados das classes).
  • Motor de execução — combina interpretação e compilação JIT.
  • Coletor de lixo (GC) — libera a memória da heap automaticamente.
Juntando as peças

Acompanhe a jornada do .class

Veja o .class passar pelo Class Loader, pelo Verificador e pelo Motor de execução — enquanto isso, objetos nascem e somem sozinhos na Heap.
Onde as classes são procuradas

Classpath vs. module path

# Classpath — tradicional, anterior ao Java 9, sem encapsulamento java -cp bin com.exemplo.Programa # Module path — Java 9+, respeita dependências e encapsulamento java --module-path mods --module com.exemplo/com.exemplo.Programa

Estrutura de uma aplicação Java

Do menor agrupamento ao maior

A hierarquia de organização do código

classe

O menor agrupamento

Classe — unidade lógica básica

Regra de ouro
  • No máximo uma classe pública por arquivo.
  • O nome do arquivo deve ser idêntico ao da classe pública.
  • Java diferencia maiúsculas de minúsculas.
Agrupamento lógico de classes

Pacote (package)

package com.exemplo.produtos; // 1ª instrução do arquivo import java.util.ArrayList; // depois do package
Agrupamento lógico de pacotes — Java 9+

Módulo (Project Jigsaw)

module com.exemplo.produtos { requires java.sql; exports com.exemplo.produtos.api; }
O maior agrupamento

Aplicação — módulos relacionados

Distribuída como .jar ou como imagem de runtime gerada pelo jlink.
Desafio rápido

Qual é a ordem certa, do menor para o maior agrupamento?

classe → pacote → módulo → aplicação
pacote → classe → módulo → aplicação
módulo → pacote → classe → aplicação
RESPOSTA
Classe é a menor unidade; pacotes agrupam classes, módulos agrupam pacotes, e a aplicação agrupa módulos.
Desafio rápido

0
1
Quantas quiser
RESPOSTA
No máximo uma — e o nome do arquivo precisa ser idêntico ao dela.

Ambiente e primeiro programa

Antes de codar ao vivo

Checklist do ambiente

  • JDK 25 instalado — conferir com java -version e javac -version
  • IDE configurada com o JDK 25 (Window → Preferences → Java → Installed JREs)
  • Compiler compliance level ajustado para 25
Se o nível de compilação estiver abaixo de 25, recursos novos (como o arquivo-fonte compacto) aparecem como erro mesmo com o JDK certo instalado.
Ao vivo

OlaMundo.java

public class OlaMundo { public static void main(String[] args) { System.out.println("Olá, mundo!"); } }
O arquivo precisa se chamar OlaMundo.java, porque a classe OlaMundo é pública.
Cada palavra tem um motivo

Entendendo o método main

PartePor que é necessária
publicPermite que a JVM chame o método de fora da classe
staticPermite chamar sem criar um objeto da classe
voidO método não devolve valor
mainNome que a JVM procura, todo em minúsculas
String[] argsRecebe os argumentos da linha de comando
Da linha de comando

Compilar e executar

javac OlaMundo.java // gera OlaMundo.class (bytecode) java OlaMundo // executa (sem a extensão .class)
Desde o Java 11: java OlaMundo.java compila em memória e executa direto — ótimo para testes rápidos.

Sintaxe simplificada do Java 25

JEP 512 — Compact Source Files and Instance Main Methods

O mesmo programa, sem cerimônia

Forma tradicional
public class OlaMundo { public static void main(String[] args) { System.out.println( "Olá, mundo!"); } }
Java 25 — arquivo compacto
void main() { IO.println("Olá, mundo!"); }
É açúcar sintático: compila para um .class comum, sem tratamento especial da JVM. Bom para exercícios; o resto do curso continua com classes explícitas.
Novidade do Java 25

A classe java.lang.IO

IO.println(Object)Escreve o objeto e quebra a linha
IO.print(Object)Escreve sem quebrar a linha
IO.readln()Lê uma linha digitada pelo usuário
IO.readln(String)Escreve um prompt e então lê a linha
Substitui, em casos simples, a combinação de System.out.println com Scanner.
Uma forma não substitui a outra

Quando usar cada sintaxe

SituaçãoForma recomendada
Exercício rápido, script, aula introdutóriaArquivo compacto, void main()
Classe de um projeto realClasse explícita, com package e main tradicional
Código chamado por outras classesClasse explícita, obrigatoriamente
O recurso não substitui a orientação a objetos — apenas adia o momento de aprendê-la.
