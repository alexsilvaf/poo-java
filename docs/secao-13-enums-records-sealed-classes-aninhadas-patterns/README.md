## 🎯 Objetivos

- criar enums com estado e comportamento;
- declarar records e seus construtores;
- projetar hierarquias `sealed`;
- distinguir classes membro, estáticas aninhadas, locais e anônimas;
- usar `switch` expressions, type patterns, record patterns, `when`, `null` e `_`.
